# Gateway behaviour that affects test results

- The client must send Logon within 15 seconds of connecting, and must wait for the Logon Response before sending anything else; messages sent earlier are rejected with a Reject `3` (code 107 "Not logged in").
- Real-time channel heartbeat interval is 3 seconds; the JSE disconnects after 3 missed intervals (Logout reason "HB expired"). Recovery channel: 5 seconds and 5 intervals.
- Message rate limit: 100 messages per second per CompID; excess messages are rejected with code 9990; more than 5 breaches in 30 seconds disconnects the CompID.
- If a logon fails for an invalid CompID, password, IP address or gateway, the JSE disconnects without sending a Logon Response. For an expired password, a locked or suspended CompID or logins not permitted, it sends a Logon Response with the reject code and then disconnects.
- Cancel on disconnect: open orders with `cancel_on_disconnect` = 1 are expired when the CompID disconnects or logs out, if the CompID is configured for it. They are reported as Expired (`execution_type` C, `order_status` 6), not Cancelled. It does not apply at end of day, when the JSE logs all users off ("Force Logout on End").
- Recovery: after a disconnect, the client logs on to the real-time channel, then to the recovery channel with the same CompID, and sends a Missed Message Request per partition. Messages missed while disconnected are not resent on the real-time channel.
- JSE Market Operations can cancel orders and cancel or correct trades on a client's behalf; the client receives the execution reports unsolicited.
- Circuit breakers: if the next trade price would differ from the static or dynamic reference price by at least the segment's tolerance, the instrument moves into a 5-minute Volatility Auction Call. The remainder of the aggressing order rests (persistent TIF) or expires; IOC orders expire with reason "Expired (circuit breaker breached)" (code 1227). Continuous trading tolerances (static/dynamic): ZA01 10%/3%, ZA02 15%/5%, ZA03 50%/25%, ZA04 70%/50%, ZA06 15%/5%. ZA01 also has a price band of ±90% of the static reference price; orders outside it are rejected (code 1202 "Invalid limit price (price band breached)").
- Self-match prevention: only for firms that opted in, enabled per CompID, with keys issued by the JSE. Applies in continuous trading and the CPX session, not in auctions, and not to pegged orders, cross orders, or TIF OPG, GFX, GFA, ATC. When an incoming order would match a resting order with the same key, the resting order is expired before any trade. The key cannot be amended. Circuit breaker checks run before self-match checks. An FOK order that cannot be filled without self-matching expires.
