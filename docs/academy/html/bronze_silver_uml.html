Bronze and silver layers: UML class diagram

How to read the diagram

What you seeWhat it means
Frame with a tab: bronze, silverA layer: the folder of that name in cloud storage. Everything inside the frame is stored in that folder.
BoxOne table, or the Excel files. The top part gives, in «angle quotes», what kind of thing it is, then its name, then its row count. The lower part lists its columns.
name : typeA column and the kind of value it holds: text; integer, a whole number; decimal, a number with decimals; timestamp, a date and time; date; boolean, true or false. The bronze columns have no type written beside them because every one is text.
{key}A column with a different value on every row: message_id numbers the silver rows 1 to 2,169,820.
Bold column in messageA column silver adds; it is not in bronze.
Name in italics, {abstract}bronze_combined_table is not a stored table. It lists the 4 columns that all 11 bronze tables have.
Line ending in a hollow triangleEach of the 11 tables at the plain ends has the columns of the box at the triangle, Timestamp, Comp ID, Message Type and source_file, as well as the columns listed in its own box.
Plain line with numbers at its endsHow many rows at one end go with one row at the other end. 1: exactly one. 0..1: none or one. 1..*: one or more. 0..*: any number, including none.
"rows copied into": 1..* to 1Each bronze table is made from one or more Excel files (the reject table from 5), and each file's rows go to exactly one table.
"merged into": 1..* to 1Each silver row is made from one or more bronze rows (the number is in copies), and each bronze row goes into exactly one silver row. 3,763,516 bronze rows become 2,169,820 silver rows.
"order link" on message: 0..* to 0..1The line starts and ends at the same table: it links rows of message to other rows of message. A New Order, cancel or amend request with no order_id takes the order_id of none or one JSE reply, and one reply can give its order_id to any number of requests.
Box with a folded corner, joined by a dashed lineA note about the box it is joined to.
